# Обзор директив

Сводная таблица всех конструкций шаблонизатора. Все директивы, кроме вывода `{{ }}`, оформляются как `{% ... %}`;
блочные — с закрывающим тегом `{% /имя %}`.

| Конструкция                  | Синтаксис                                                    | Тип       | Аргумент                                                                                  |
|------------------------------|--------------------------------------------------------------|-----------|-------------------------------------------------------------------------------------------|
| [Вывод](03-print-and-raw.md) | `{{ путь }}`                                                 | одиночная | точечный путь, с HTML-экранированием                                                      |
| [raw](03-print-and-raw.md)   | `{% raw путь %}`                                             | одиночная | точечный путь, без экранирования                                                          |
| [if](01-if.md)               | `{% if путь %}...{% elseif путь %}...{% else %}...{% /if %}` | блочная   | точечный путь, приводится к `bool`                                                        |
| [foreach](02-foreach.md)     | `{% foreach [ключ,]значение in путь %}`                      | блочная   | путь к массиву                                                                            |
| [layout](04-layout.md)       | `{% layout имя %}...{% /layout %}`                           | блочная   | имя каркаса без кавычек                                                                   |
| [component](05-component.md) | `{% component vendor:name [templateName] [options] %}`       | одиночная | имя компонента, опционально шаблон и путь к опциям                                        |
| [include](06-include.md)     | `{% include type filename [position] %}`                     | одиночная | `type` — `css`/`js`; `filename` — путь к переменной контекста; `position` — `head`/`body` |
| [csrf](07-csrf.md)           | `{% csrf %}`                                                 | одиночная | нет                                                                                       |
| [defer](08-defer.md)         | `{% defer путь %}` или `{% defer путь raw %}`                | одиночная | точечный путь, опционально флаг `raw`                                                     |

Общие для всех: аргумент почти всегда — точечный путь к значению в контексте (`user.profile.name`), а не произвольное
выражение; операторы сравнения и арифметика не поддерживаются нигде (см. [Основы синтаксиса](../03-syntax-basics.md)).
Директивы `layout`, `component`, `include`, `defer` работают только в режиме компиляции — интерпретация (`render()`) для
них не реализована.
