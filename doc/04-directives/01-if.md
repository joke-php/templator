# Директива {% if %}

## Назначение

Условный вывод части шаблона в зависимости от значения переменной из контекста.

## Синтаксис

```
{% if путь %}
    ...контент...
{% elseif путь %}
    ...контент...
{% else %}
    ...контент...
{% /if %}
```

Закрывающий тег — только `{% /if %}` (форма `{% endif %}` не поддерживается). Ветки `elseif` и `else` необязательны, `elseif` может повторяться.

**Важно:** аргумент `if`/`elseif` — это точечный путь к значению в контексте (`user.admin`), а не произвольное выражение. Операторы сравнения и логические операторы (`==`, `!=`, `>`, `<`, `&&`, `||`) шаблонизатор не разбирает — условие всегда одно значение, приводимое к `bool`.

## Примеры использования

### Простое условие

```php
$response->show('pages/profile.php', [
    'user' => ['isLogged' => true],
]);
```

```html
{% if user.isLogged %}
    Вы вошли в систему
{% /if %}
```

### Условие с elseif и else

Поскольку сравнение строк (`role == 'admin'`) не поддерживается, ветвление по нескольким значениям оформляется через отдельные булевы флаги, подготовленные в контроллере:

```php
$role = 'editor';
$response->show('pages/dashboard.php', [
    'isAdmin' => 'admin' === $role,
    'isEditor' => 'editor' === $role,
]);
```

```html
{% if isAdmin %}
    Панель администратора
{% elseif isEditor %}
    Панель редактора
{% else %}
    Личный кабинет
{% /if %}
```

### Проверка существования переменной

Отсутствующий ключ при компиляции даёт `null`, который приводится к `(bool)` в `false` — то есть просто отсутствующая переменная уже работает как «пусто»:

```html
{% if user.middleName %}
    Отчество: {{ user.middleName }}
{% /if %}
```

Если нужно явно отличать «не задано» от «пустая строка», подготовьте отдельный флаг в контексте (`hasMiddleName`), а не полагайтесь на неявное приведение.

### Использование точечной нотации

Путь может быть любой глубины, но каждый сегмент — ключ массива:

```php
$response->show('pages/profile.php', [
    'user' => ['profile' => ['verified' => false]],
]);
```

```html
{% if user.profile.verified %}
    Аккаунт подтверждён
{% else %}
    Требуется подтверждение
{% /if %}
```

### Сравнения и логические операторы

Не поддерживаются. Любое сравнение (`$a === $b`, `$a > 10`), объединение условий (`&&`, `||`) или отрицание нужно вычислить в PHP-коде контроллера и передать в шаблон готовым булевым значением:

```php
$response->show('pages/orders.php', [
    'canCancel' => $order->status === 'pending' && $order->createdAt > $limit,
]);
```

```html
{% if canCancel %}
    <button>Отменить заказ</button>
{% /if %}
```

## Особенности

Истинность значения определяется обычным приведением PHP к `bool`: false — `false`, `0`, `0.0`, `''`, `'0'`, `null`, пустой массив `[]`; всё остальное — true. Это касается и отсутствующих ключей контекста (см. выше).

Вложенные условия поддерживаются без ограничений — `{% if %}` внутри `{% if %}` компилируется как обычный вложенный PHP-код:

```html
{% if user.isLogged %}
    {% if user.profile.verified %}
        Добро пожаловать, {{ user.profile.name }}
    {% else %}
        Подтвердите аккаунт
    {% /if %}
{% /if %}
```
