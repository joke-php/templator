# Директива {% foreach %}

## Назначение

Итерация по массиву из контекста с выводом контента для каждого элемента.

## Синтаксис

```
{% foreach значение in коллекция %}
    ...контент...
{% /foreach %}

{% foreach ключ, значение in коллекция %}
    ...контент...
{% /foreach %}
```

Аргумент разбирается регулярным выражением `(\w+)(?:\s*,\s*(\w+))?\s+in\s+(.+)` — обязателен пробельный разделитель `in`, имена переменных — только буквенно-цифровые идентификаторы, `коллекция` — точечный путь к массиву в контексте (как и в `{% if %}`, произвольные выражения не поддерживаются). Закрывающий тег — `{% /foreach %}`.

## Примеры использования

### Простой цикл по массиву

```php
$response->show('pages/list.php', [
    'items' => ['Первый', 'Второй', 'Третий'],
]);
```

```html
{% foreach item in items %}
    <li>{{ item }}</li>
{% /foreach %}
```

### Цикл с ключом

```php
$response->show('pages/list.php', [
    'map' => ['ru' => 'Русский', 'en' => 'English'],
]);
```

```html
{% foreach key, value in map %}
    <li>{{ key }}: {{ value }}</li>
{% /foreach %}
```

### Доступ к свойствам элемента

Внутри цикла переменная элемента доступна как локальная (`user`), а обращение к её вложенным ключам — обычной точечной нотацией:

```php
$response->show('pages/users.php', [
    'users' => [
        ['name' => 'Alex', 'profile' => ['verified' => true]],
        ['name' => 'Nina', 'profile' => ['verified' => false]],
    ],
]);
```

```html
{% foreach user in users %}
    <p>{{ user.name }} — {% if user.profile.verified %}подтверждён{% else %}не подтверждён{% /if %}</p>
{% /foreach %}
```

### Вложенные циклы

Циклы можно вкладывать без ограничений — используйте разные имена переменных для внешнего и внутреннего уровня, иначе внутренний цикл перезапишет переменную внешнего:

```php
$response->show('pages/groups.php', [
    'groups' => [
        ['title' => 'Группа A', 'items' => ['a1', 'a2']],
        ['title' => 'Группа B', 'items' => ['b1']],
    ],
]);
```

```html
{% foreach group in groups %}
    <h2>{{ group.title }}</h2>
    <ul>
    {% foreach item in group.items %}
        <li>{{ item }}</li>
    {% /foreach %}
    </ul>
{% /foreach %}
```

## Локальные переменные цикла

Специального объекта цикла (аналога `loop.index`/`loop.first`/`loop.last` из Twig) нет. Единственные доступные переменные — те, что заданы в самой директиве (`item`, либо пара `key, value`). Чтобы получить порядковый номер итерации, используйте числовой ключ явно:

```html
{% foreach index, item in items %}
    <li>{{ index }}: {{ item }}</li>
{% /foreach %}
```

Если нужен номер с 1, а не с 0, или признак «первый/последний элемент» — вычислите это в контроллере и передайте отдельным массивом (например, обогатите каждый элемент полем `isFirst`/`isLast` до передачи в `show()`).

## Особенности

**Пустая коллекция.** Если массив пуст, тело цикла просто не выполняется ни разу — ни ошибки, ни вывода.

**Не массив.** И в скомпилированном коде, и в режиме интерпретации значение не приводится к массиву принудительно: код напрямую передаёт результат в `foreach`. Если по указанному пути лежит не массив (строка, число, `null`), PHP выдаёт предупреждение (`Warning: Foreach argument must be of type array|object`) и тело цикла также не выполняется — это не фатальная ошибка, но и не тихий пропуск: предупреждение попадёт в лог/вывод ошибок PHP. Отсутствующий ключ контекста в режиме интерпретации трактуется как пустой массив по умолчанию и цикл просто не выполняется без предупреждений.
