# Руководство по миграции с версии 1.x на 2.0

В версии 2.0 изменён синтаксис закрывающих тегов парных директив для улучшения
читаемости шаблонов и соответствия общепринятым практикам (аналогично Twig, Blade).

| Вариант v1.x                                           | Вариант v2.x+                                            |
|--------------------------------------------------------|----------------------------------------------------------|
| {% if путь %}...{% /if %}                              | {% if путь %}...{% endif %}                              |
| {% foreach [ключ,]значение in путь %}...{% /foreach %} | {% foreach [ключ,]значение in путь %}...{% endforeach %} |
| {% layout имя %} ... {% /layout %}                     | {% layout имя %} ... {% endlayout %}                     |

## Варианты миграции

Есть два пути внести изменения в существующих проектах:

### Вариант 1: Обновление шаблонов (рекомендуется)

Измените во всех шаблонах вид закрывающего тега согласно таблице выше.
Это обеспечит совместимость с будущими версиями и улучшит читаемость кода.

### Вариант 2: Обратная совместимость через конфигурацию

Архитектура шаблонизатора позволяет гибко управлять синтаксисом. Если обновление шаблонов нецелесообразно или вы
предпочитаете старый стиль, вы можете в любой момент переопределить назначения тегов в провайдере приложения:

```php
class ApplicationProvider extends AbstractProvider
{
    /**
     * @param ServiceContainer $serviceContainer контейнер зависимостей приложения
     */
    public function __construct(
        private readonly ServiceContainer $serviceContainer,
    ) {}
    
    public function boot(): void {
        /** @var TemplatorConfig $config */
        $config = $this->serviceContainer->get(TemplatorConfig::class);
        $stmt = StatementToken::class;
        
        // Переопределяем закрывающие теги на формат v1.x
        $config->directiveCollection->upsert($stmt, 'if', '/if', ['else', 'elseif']);
        $config->directiveCollection->upsert($stmt, 'foreach', '/foreach');
        $config->directiveCollection->upsert($stmt, 'layout', '/layout');
    }
}
```

Этот механизм является штатным способом кастомизации шаблонизатора и может использоваться не только для обратной
совместимости, но и для адаптации синтаксиса под специфические требования проекта.
